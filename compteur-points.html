Site Web & Bot Discord

[PHOTO DU PROJET ICI]

Pour faciliter nos soirées et jeux entre amis, j'ai développé de A à Z une solution combinant un site web et un bot Discord pour compter et suivre les scores en temps réel.

Fonctionnalités & Développement :

  • Interface Web : Développement d'un site web dynamique permettant d'ajouter, modifier ou consulter les scores via une interface claire et intuitive.
  • Bot Discord : Programmation d'un bot permettant d'interagir avec la base de scores directement depuis nos serveurs textuels grâce à des commandes personnalisées.
  • Base de données & API : Liaison entre le site web et le bot Discord pour que les données soient synchronisées en temps réel.

Un projet très formateur sur la partie développement (Full-stack) et la communication entre différentes interfaces via des API.
